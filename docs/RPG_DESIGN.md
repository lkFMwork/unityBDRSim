# RPG Layer — Create-Your-BDR

The call simulator is the "encounter." The RPG layer wraps it so the player owns
a character, makes meaningful build choices, and grows a career over many calls.

## Create your BDR

In the `CharacterCreate` scene you set:

- **Name** — first / last.
- **Background (archetype)** — a starting attribute spread with flavor:
  *The Closer*, *The Hunter*, *The Consultant*, *The Natural*. You then distribute
  **6 bonus points** on top (can't drop below the archetype's base).
- **Look** — a live 3D avatar (built from primitives) you customize: skin tone,
  outfit, accent, hair color, build, and height. It sways/idles so the 3D reads.

The avatar is generated by [`AvatarBuilder`](../Assets/Scripts/UI/AvatarBuilder.cs).
Its `SetConfig` method is the seam to swap in a real rigged model + Animator later
without changing anything else.

## Attributes → call effects

Attributes run 1–10 (5 = neutral). [`CharacterModifiers`](../Assets/Scripts/Simulation/CharacterModifiers.cs)
turns them into concrete levers on a call — this is what makes a build *matter*:

| Attribute | Effect on a call |
| --- | --- |
| **Charisma** | Higher starting trust; bonus to Rapport scoring |
| **Negotiation** | Rate "headroom" — prospects accept higher rates before balking |
| **Product Knowledge** | Bonus to Value Articulation and Objection Handling scoring |
| **Resilience** | Patience drains slower (you wear down less under pressure) |
| **Prospecting** | Bonus to Discovery scoring |

The effects are deterministic and unit-tested, and they feed directly into the
existing `CallSession` / `NegotiationEngine`.

## Progression

[`ProgressionSystem`](../Assets/Scripts/Simulation/ProgressionSystem.cs) handles
XP, levels, skill points, and career rank:

- **XP per call** = grade (0–100 from the scorecard) + an outcome bonus
  (won a load > trial > follow-up > rejected > hung up).
- **Leveling** uses a rising cost curve; each level grants **2 skill points**.
- **Career rank** climbs with level: BDR → Senior BDR → Account Executive →
  Sales Manager.

Career stats (calls made, deals won, hang-ups, total weekly margin won, win rate)
accumulate on the character and show on the menu.

## Persistence

[`SaveSystem`](../Assets/Scripts/Core/SaveSystem.cs) writes the character to JSON
under `Application.persistentDataPath`. `GameManager` loads it on boot, so the BDR
and their career persist between sessions. "New BDR" on the menu starts over.

## Flow

```
MainMenu ──(no save)──► CharacterCreate ──save──► MainMenu
   │                                                  │
   └──────────── pick scenario ──► CallFloor ─────────┘
                                      │
                              call ends → award XP,
                              update career, save, show
                              grade + level-up
```
